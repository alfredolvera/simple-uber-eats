# Simple Uber Eats identity

All Simple Uber Eats work uses the GitHub identity `alfredolvera`, including
commits, releases, pull requests, reviews and comments. `djultra64` is reserved
for the user's video game projects and must never be used as a fallback here.

Before any external write, verify the authenticated account. If the
`alfredolvera` connection lacks permission, obtain an authorized session for
that account; do not post or publish with another account.

The separate GitHub CLI profile for this project is
`GH_CONFIG_DIR=/var/home/alfredo/.config/gh-simple-uber-eats`. Check its logged-in
user before using it. Keep authentication credentials outside the repository.
