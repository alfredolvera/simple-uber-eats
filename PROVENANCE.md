# Provenance

Simple Uber Eats is an independently maintained Home Assistant integration.

The current 3.x implementation was independently reimplemented from observable
behavior, documented Home Assistant and Python interfaces, automated behavioral
tests, and validation with live Uber Eats orders. Earlier community Uber Eats
integrations informed the project's history and functional requirements; their
unlicensed source code is not intended to be part of the 3.x release tree.

The local Simple Uber Eats icon and logo are original project artwork composed
from basic geometric vector shapes and are not derived from third-party brand
assets.

Uber Eats and other third-party names and trademarks belong to their respective
owners. Simple Uber Eats is an unofficial community project and is not
affiliated with, endorsed by, or supported by Uber.
